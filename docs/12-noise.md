## 核心概念

### 1. 伪随机 vs 噪声

| <br /> | 伪随机数（fract + sin） | 噪声函数          |
| ------ | ----------------- | ------------- |
| 连续性    | ❌ 不连续，相邻点差异大      | ✅ 连续，相邻点平滑过渡  |
| 视觉效果   | 杂乱的雪花             | 云雾、地形、火焰等有机效果 |
| 可预测性   | 哈希，完全不可预测         | 梯度插值，有规律      |

**类比**：随机数 = 掷骰子（每次独立）；噪声 = 山脉高度（相邻接近，整体不可预测）

### 2. Perlin Noise 算法

1. `floor(p)` → 整数网格坐标
2. `fract(p)` → 格子内小数坐标
3. `hash(i + offset)` → 四个角的随机梯度向量（vec2）
4. `dot(梯度, 距离向量)` → 四个角对当前点的影响值
5. Hermite 插值 `f*f*(3-2*f)` → 平滑混合

### 3. FBM（分形布朗运动）

叠加多个频率/振幅的噪声层：

* 每层频率 ×lacunarity（通常 2.0）

* 每层振幅 ×persistence（通常 0.5）

* octaves 越多细节越丰富，但计算量线性增长

| 层 | 频率 | 振幅     | 效果   |
| - | -- | ------ | ---- |
| 1 | ×1 | ×1     | 大轮廓  |
| 2 | ×2 | ×0.5   | 中等细节 |
| 3 | ×4 | ×0.25  | 细节   |
| 4 | ×8 | ×0.125 | 微细节  |

### 4. 顶点变形

在顶点着色器中用噪声偏移 position：

```glsl
float n = fbm(pos.xy * scale + time, octaves, lacunarity, persistence);
pos += normal * n * strength;
```

法线重算用有限差分法：对 pos 做微小偏移 (eps)，算切线，再叉积得到新法线。

| -------------------------------- | ---------------------------- |

| `cross(a, b)`                    | 叉积（求法线）                      |

## 常见错误

* **噪声值域映射**：Perlin Noise 输出约 \[-0.7, 0.7]，需要 `* 0.5 + 0.5` 映射到 \[0, 1]

* **顶点着色器不能用** **`if`** **分支**：GLSL 中 if/else 在顶点着色器中性能差，尽量用 mix/step

* **法线不重算**：顶点变形后直接用原始法线 → 光照会"滑动"

* **octaves 太多**：8 层以上性能下降明显，视觉差异不大，4\~6 层通常够用

### 案例一：风吹草地（sin 同频 → 噪声风场）

**问题**：`sin(time)` 输出只依赖时间，所有草叶同频同相 → 机械、假

**修复思路**：把草叶位置加进噪声输入，`bend = noise(草根位置 + 时间·风向)`

* 用 `instanceMatrix[3].xz` 取每根草的根部世界坐标（草的"身份"）

* 相邻草坐标相近 → 输出相近 → 连绵风浪；远处各自独立 → 无机械感

* 沿风向平移采样窗 → 阵风"扫过"草地而非原地抖动

* 叠两层噪声：低频阵风（大片起伏）+ 高频抖动（细碎颤动）

* 摆动量乘 `pow(uv.y, 1.5)`：根部固定、叶尖摆动最大

**实现**：`InstancedMesh`（2200 草叶）+ 顶点着色器风场

### 案例二：FBM 云朵（均匀灰色 → 层次分明）

**问题**：整片均匀灰色，看不到云的形状

**病因（两环叠加）**：

1. persistence = 1.0：各层等幅叠加，正负值互相抵消 → 值域坍缩在 0.5 附近
2. `smoothstep(0.0, 1.0)` 宽区间：远宽于实际值域 → 全屏落在同一灰阶

**修复思路**：

* persistence = 0.5（幅度快速衰减）+ 按理论满量程 `Σ amp^i` 归一化

* 窄区间 `smoothstep(coverage ± 0.1)` 贴着实际值域扫 → 云边缘对比出来

* **调试模式**：直接输出 FBM 原始值灰度图，用取色器量 min/max 确认值域

**实测数据**：错误模式 std=5.4（均匀灰）；修复模式 std=20.1（层次分明）

### 案例三：噪声地形（Math.random → 噪声高度场）

**问题**：`Math.random()` 与位置无关 → 相邻顶点高度毫无关系（尖刺）+ 逐帧结果不同（抖动）

**修复思路**：`h = fbm(pos.xz)`，高度是位置的连续函数

* 相邻顶点坐标只差一点 → 输入相近 → 输出相近 → 平滑连绵

* 同一顶点每帧结果相同（确定性）→ 画面稳定

* 有限差分法线（四邻域采样）→ 山脉光影正确

**错误模式**（GPU 等价的 random：`random(vec2(gl_VertexID, seed))`）：

* 静态：满屏尖刺，法线崩坏

* 逐帧：把时间混进 random 输入 → 前后帧毫无关联 → 疯狂抖动

**实测数据**：噪声模式边缘能量 0.43（平滑）；随机模式 3.8（尖刺，9 倍高频）

### 附加思考题一：体素地形的噪声选型（实战场景）

**场景**：体素沙盒游戏（类 Minecraft），逐体素采样 3D 噪声决定该处放石头、泥土还是空气。老代码用 Perlin Noise，新同事建议换 Simplex Noise。

**问题**：

1. 在这个场景下，Simplex 相对 Perlin 有什么优势？
2. 换成 Simplex 值得吗？
3. 有没有什么情况 Simplex 并不比 Perlin 好？

**参考答案**：

* **优势一：计算复杂度随维度增长更慢**。Perlin 在 N 维需要 2^N 个格点（3D 是 8 个角点），Simplex 只需 N+1 个（3D 是 4 个）。体素逐点采样 3D 噪声，采样次数 × 世界体积，性能差距会被乘出来

* **优势二：没有明显的方向性伪影**。Perlin 在格点整数坐标处值为 0，轴向方向会出现隐约的"网格感"；Simplex 用偏斜的单纯形网格，方向偏差更弱，山脊谷地走向不会老沿 X/Z 轴排

* **优势三：更各向同性**。2D Perlin 沿对角线与沿轴向的特征频率差 √2 倍，远看有方形纹理感；Simplex 基本消除

* **值得换吗**：值得。3D 场景下 Simplex 格点数只有 Perlin 一半，性能收益实打实；但要认识到体素化本身（方块轴对齐）会掩盖一部分伪影问题，视觉收益打折扣

* **Simplex 不占优的情况**：

  * 2D 高度图场景（3 vs 4 个格点，性能差距可忽略）

  * 想要"可控的网格感"——风格化地形反而把 Perlin 轴向伪影当特性用

  * 已用 improved Perlin（2002 改良版），与 Simplex 实际差距已不大

  * Simplex 的偏斜坐标与单纯形划分更难读、更容易写错

  * 历史专利问题（US6867776，2022 年初已过期）——老代码坚持 Perlin 的常见原因

### 附加思考题二：拉近后冰面变"糊"（调试推理）

**场景**：法线扰动的冰面材质（噪声给法线加扰动，制造凹凸冰晶效果）。摄像机拉近、表面细节被放大时，凹凸效果变"糊"——像被磨砂过，失去近距离应有的锐利冰晶感。

**问题**：

1. 这可能和噪声的什么特性有关？
2. 你会怎么改？

**参考答案**：

* **病因：噪声频率固定，没有多尺度细节储备**。真实冰晶表面有分形细节——凑多近都有更细的凹凸；而固定频率噪声的凹凸有固定特征尺度。摄像机拉近 = 在越来越小的窗口里看同一批坡，坡被放大、梯度变平缓、法线扰动在屏幕上变化率下降 → specular 变成大片缓慢渐变 → "磨砂感"。这和纹理拉近模糊不是一回事，但直觉类似：**把固定的信息量放大，得到的是模糊，不是细节**

* **改法一（正解）：fBm 分形叠加**。多倍频叠加，频率逐级翻倍、幅度逐级衰减（4\~6 层通常够用），"不管多近都有更细的起伏"

* **改法二：换噪声类型**。Value Noise 高频下插值曲线很"软"，天然糊；换 Perlin/Simplex 梯度噪声，或用 Voronoi 细胞噪声——晶界天然像冰的裂纹结构，锐利感比连续噪声好得多

* **改法三：屏幕空间细节**。把扰动挪到屏幕空间 UV 采样，摄像机拉近时自动提高有效频率，制造"怎么凑近都有细节"的错觉（注意表面滑动感，需配合表面空间细节）

* **改法四：预烘焙高频法线贴图**。噪声只负责低频大形状，高频细节存 normal map。适合固定资产、不需纯程序化的场景

* **推荐组合**：fBm 多倍频做骨架 + Voronoi 做冰晶特征层，是程序化冰面材质的标准做法
